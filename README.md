# Kawempe Phone Accessories POS System

A command-line Point-of-Sale (POS) inventory and sales tracker built with Python. This system helps a phone accessories shop manage stock, process sales, and generate receipts.

## Features
*   **Class-Based Inventory:** Uses Object-Oriented Programming (OOP) to manage products.
*   **Error Handling:** Uses `try/except` to prevent crashes when users type text instead of numbers.
*   **Stock Management:** Automatically checks if a product is out of stock before completing a sale.
*   **File Generation:** Saves a permanent record of all sales to a `sales.txt` file.

## Technologies Used
*   Python 3
*   Object-Oriented Programming (Classes, Methods)
*   File I/O (Reading and Writing files)
